# Leon Frick – Minimal warm hero

En strammere versjon med mye mindre tekst:

- hero med kun navn, én linje og to knapper
- Spotify som hovedinnhold
- korte tjeneste- og samarbeidslister
- kort artistbio
- tekster beholdt i lukkede accordions
- enkel kontaktseksjon

Klar for GitHub Pages. Last opp innholdet i denne mappen til roten av repoet og publiser fra `main` / `/root`.
